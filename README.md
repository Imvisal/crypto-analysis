# Crypto Analyzer

Single-page crypto analysis app. Pick any Binance USDT coin and get a BUY / SELL / WAIT signal
based on Technical (50%), Fundamental (25%) and Sentiment (25%) analysis, with reasons,
support/resistance levels, stop-loss and take-profit suggestions.

Data sources (all free, called from the browser): Binance, CoinGecko, alternative.me Fear & Greed.

No build step. Just static `index.html`.

> Educational tool only. Not financial advice.
